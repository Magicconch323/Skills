# 书摘、典故与名言

## 1. 选用原则
- 贴切 > 有名；每篇 1~3 条，中外搭配更好。
- 优先原典原文，其次权威译本并注明译者。
- 典故讲出故事：人物、场景、结果、寓意，3~5 句。

## 2. 核实流程（每条必走）
1. 找原始出处：作者、书名、篇章/卷次、版本或译者，最好有页码或在线原文链接。
2. 在线原文：中国哲学书电子化计划 ctext.org、维基文库 zh.wikisource.org；西方原著用 Project Gutenberg、Internet Archive；现代作品查出版社或豆瓣书目确认版本。
3. 名言核查：Quote Investigator（quoteinvestigator.com）、Wikiquote 的 Misattributed / Disputed 部分。
4. 两个独立可靠来源对得上才算通过；只出现在鸡汤号、图片里的不用。
5. 查不到就写「此语广为流传，但未查到可靠出处」或不用。

## 3. 伪名言信号
- 名人 + 鸡汤味 + 无书名篇名（鲁迅、爱因斯坦、张爱玲、杨绛、莫言高发）。
- 现代口吻挂在古人名下；只有译文没有原文。
- 已知案例（用前再核）：「善良是信者对不信者的愧怍」误挂鲁迅，「愧怍」出自杨绛《老王》；「我不同意你的观点，但誓死捍卫你说话的权利」非伏尔泰原话，出自 Evelyn Beatrice Hall（笔名 S. G. Tallentyre）1906 年《The Friends of Voltaire》的概括。

## 4. 引用格式
> 「恻隐之心，人皆有之。」
> ——《孟子·告子上》
- 现代著作：`——费孝通《乡土中国·差序格局》`（注出版社与年份）。
- 译著：`——亚当·斯密《国富论》第一卷第二章（郭大力、王亚南 译）`。
- 网络：`——作者，《标题》，网站，日期，[链接](URL)`。
- 转述写「大意是」，不加引号。
- 纠错：「来源与核对说明」写「素材称 X 出自 A，经核对实出 B（链接）」。

## 5. 引文卡复用
- 核实过的引文记到 `知识库/资源索引/引文卡.md`（引文、出处、链接、核实日期），下次免重复核查。
