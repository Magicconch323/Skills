# 学习科学与教学法

## 1. 有证据支撑的学习策略
参考 Dunlosky 等 2013《Improving Students' Learning With Effective Learning Techniques》（Psychological Science in the Public Interest）与 Weinstein、Sumeracki《Understanding How We Learn》（用前上网核实）：
| 策略 | 做法 | 推送里怎么用 |
|---|---|---|
| 间隔重复 | 隔一段时间再回顾 | 讲过的知识点 7 天、30 天后在新推送里一句话回扣 |
| 提取练习 | 主动回想而非重读 | 结尾留一个回想小问题 |
| 精细化 | 追问为什么、怎么样 | 每个知识点讲清一个「为什么」 |
| 具体例子 | 抽象配实例 | 至少一个生活例子 |
| 双重编码 | 文字 + 图 | 完整版附一张表或简图（visual-explanation） |
| 交错 | 不同主题穿插 | 不连续两天讲同一学科 |
- 遗忘曲线源自艾宾浩斯 1885《论记忆》，不要说成精确公式。

## 2. 费曼学习法
1. 选概念 2. 讲给聪明的 12 岁孩子听 3. 卡壳处回原文补 4. 再简化、用类比。术语一出现就解释。

## 3. 故事化与类比
- 结构：钩子（反常识问题或场景）→ 人物/故事 → 概念 → 回到生活。
- 类比标边界：「有点像……，不同在于……」。典故来源规则见 `quotes-and-allusions`。

## 4. 认知负荷（Sweller）
- 每日推送：1 个知识点、3~5 条要点、新术语 ≤ 3 个；先整体后细节；挂钩已讲内容。

## 5. 每日 9 点推送模板
- 文字 2~4 句：钩子 + 一句话说清 + 为什么值得知道。
- 一张卡片：标题 = 知识点名，摘要 3~5 条；遵守选项卡规则（一卡一问、allowCustom 不做成选项、≤ 6 个选项、无搁置选项），选项如「看完整内容」「讲个相关故事」「和我的生活有什么关系」。
- 主人点开 → 发完整知识点（排版按 `knowledge-note-format`），结尾一个回想小问题。
- 记入 `Bots/图书馆/已讲清单.md`；挑选顺序：新入库 → 久未讲 → 贴近主人近期关注。
