# 图解表达

## 1. 什么内容用什么图
| 内容关系 | 形式 |
|---|---|
| 两种以上事物对比 | 对照表（如 乡土社会 vs 现代社会） |
| 先后发展 | 时间线（列表或 Mermaid timeline） |
| 因果、流程 | Mermaid flowchart |
| 概念层级 | 缩进列表或 Mermaid mindmap |
| 人物与学派关系 | 表格：人物｜年代｜主张｜代表作 |
| 理论争论 | 两栏表：观点｜代表人物｜证据｜反驳 |

## 2. 写法
- Mermaid 用代码块 ```mermaid；Notion 代码块选 Mermaid 语言可渲染（同步时设置语言；用前核实当前支持情况）。
- 节点文字 ≤ 8 个字；一图 ≤ 12 个节点，超过就拆。
- 表格 ≤ 5 列，单元格一句话，不在单元格换行。
- 图下面写一句「这张图说明……」，不能只放图。

## 3. 示例
```mermaid
flowchart LR
  A[恻隐之心] --> C[行善]
  B[心理预期] --> C
  C --> D[声誉回报]
  D --> B
```
