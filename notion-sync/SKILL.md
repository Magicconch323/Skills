# 本地 ↔ Notion 同步

## 0. 启用条件
- 主人 2026-10-16 说「先别迁移」。**未收到主人启动迁移的明确指示前，不在 Notion 创建或修改任何页面**，只可读。
- 授权失效时找大管家；重新授权前先关 VPN（VPN 会拦本地回跳）。

## 1. 原则
- **本地为主（single source of truth）**：`E:\coding\知识库\` 是母本，bots 依赖它；Notion 是阅读视图。冲突时以本地为准；主人在 Notion 里改了内容，先回写本地再同步。
- 单向为主：本地 → Notion；Notion 评论只读回来作参考。

## 2. Notion 结构（主人规则）
- 一个总页面「知识库」（文件夹）装所有知识内容。
- 一学科一页；同学科知识点作为该页的 H2 小节（按收录日期或专题顺序）。
- 出现上级学科内容 → 该页改名为上级学科，原学科整体降为一节（H2 学科名，H3 知识点），并入新内容。只合并不删除。
- 页首放本学科导语 callout + 小节目录（table of contents 块）。

## 3. 映射表
本地维护 `知识库/notion-映射.md`：
| 本地路径 | Notion 学科页 | 页面 ID | 小节标题 | 内容哈希 | 最后同步 |
|---|---|---|---|---|---|
- 学科页改名或合并时，更新所有涉及行；页面 ID 不变则只改名。

## 4. 增量同步流程
1. 列出本地知识点，计算正文哈希（如 SHA-1），与映射表比对：新增 / 变更 / 未变。
2. 新增：找到（或按规则新建 / 向上合并）学科页，追加 H2 小节。
3. 变更：替换该小节内容（定位标题，替换到下一个同级标题前）。
4. 本地删除或移动：不自动删 Notion，列清单问主人。
5. 写回映射表，更新时间用 UTC+8。

## 5. 格式转换
- frontmatter → 小节开头一行灰色属性：学科 · 标签 · 收录日期（或 toggle「元信息」）。
- `> 💡 …` → callout；`<details>` → toggle；`> 「…」——出处` → quote；表格 → table。
- 库内相对链接 `[标题](../x.md)` → 指向对应学科页的 mention（同页时链到小节锚点，做不到就写「见本页『标题』一节」）。
- 外链保留；图片需上传后替换。
- 使用 MCP `user-Notion` 的 notion-create-pages / notion-update-page / notion-fetch，调用前先看工具 schema。

## 6. 校验
- 同步后抽查 2 个页面：标题层级、表格、引用、链接可点；在当日 21:00 汇报里写同步了几条。
