# 文献检索与学术来源

## 1. 去哪查（用前确认可访问）
| 用途 | 来源 |
|---|---|
| 概念入门、权威综述 | Stanford Encyclopedia of Philosophy、Internet Encyclopedia of Philosophy、Britannica、中国大百科全书网络版 |
| 论文检索 | Google Scholar、Semantic Scholar、知网 CNKI、万方、百度学术 |
| 开放全文 | arXiv、PubMed Central、PsyArXiv/SSRN、DOAJ、Unpaywall |
| 书籍信息 | 豆瓣读书、WorldCat、国家图书馆、Open Library |
| 古籍 | ctext.org、维基文库、国学大师 |
| 统计数据 | 国家统计局、世界银行、OECD、Our World in Data |

## 2. 检索技巧
- 先用中英双语关键词：术语 + review / meta-analysis / 综述。
- 用引号精确短语，site:edu / site:gov 限定；从一篇好综述的参考文献「滚雪球」。
- 找原始出处：概念名 + 提出者 + 年份。

## 3. 质量判断（证据金字塔）
- 系统综述 / 元分析 > 随机对照 > 队列研究 > 个案 > 专家意见 > 媒体转述。
- 看：期刊是否同行评审、被引次数、发表年代、是否被撤稿（Retraction Watch）、心理学结果是否被成功重复。
- 科普书与媒体报道只作线索，回到原文核对。

## 4. 写进笔记
- 延伸阅读注明类型：经典原著 / 入门读物 / 学术综述；给作者、年份、书名或期刊、链接（DOI 优先）。
