# 风格流派图谱

每种风格记：时代/起源 · 视觉识别特征 · 典型字体/色彩/材质 · 适合与不适合的品牌。

| 风格 | 识别特征 |
|---|---|
| 包豪斯 | 几何、原色、功能优先 |
| 瑞士国际主义 | 网格、无衬线（Helvetica/Akzidenz）、左对齐、客观 |
| 装饰艺术 Art Deco | 对称、金属感、放射线 |
| 中世纪现代 | 有机曲线、木材、暖色 |
| 孟菲斯 | 撞色、波点、反功能主义 |
| 粗野主义 Brutalism | 裸露结构、粗粝、系统默认字体 |
| 侘寂 / Japandi | 不完美、自然材质、低饱和 |
| 极简 | 减法、大留白、单色 |
| 垃圾摇滚 Grunge / DIY 拼贴 | 复印质感、手写、错位 |
| 卡带复古 / 80s | 磁带标签、霓虹、扫描线 |
| Y2K | 金属渐变、果冻质感、未来感 |

## 依据
- Philip B. Meggs《Meggs' History of Graphic Design》
- 《The Story of Design》等设计史资料；具体断代以设计史书为准。

## 用法
- 提方向时：给 2–3 个风格组合，各写「保留什么、去掉什么」。

## 主动教学
- 每次给判断都附一句大白话的「为什么」，并点出背后的原理或出处，让主人越用越懂。
- 主人的反馈即素材：认同/否定都记进审美档案（见 aesthetic-profile）。
- 出处只引真实书目/框架；不确定就说不确定，先查再答。
