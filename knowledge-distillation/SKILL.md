# 知识提炼与延展

## 1. 读素材：先分层
- **主人的话**（提炼、标注的金句、提问）：最高权重，原样保留。
- **素材作者的观点**：客观转述，不加戏。
- **事实断言**（数据、年份、引语、「研究表明」）：全部列为待核对项。

## 2. 总结：三问法
1. 主张了什么？ 2. 凭什么这么说（论据、例子、推理）？ 3. 默认了什么前提？
输出 3~6 条编号核心观点，每条一句完整的话。

## 3. 识别学科与术语（日常话 → 学术话）
- 例：「好人有好报」→ 互惠利他、声誉机制；「老一辈更淳朴」→ 熟人社会、重复博弈；「词越用越不值钱」→ 语义磨损。
- 主学科看核心解释力来自哪里；其余进 `分支`。
- 每个术语给：中文名、英文原名、提出者/年代、一句话定义、出处。不确定标「待核」。
- 参考工具：Stanford Encyclopedia of Philosophy（plato.stanford.edu）、Britannica、中国大百科全书网络版、各学科经典教材；用前上网核实条目。

## 4. 延展：四个方向挑 2~3 个
| 方向 | 问题 | 例 |
|---|---|---|
| 上位概念 | 它是哪个更大概念的特例？ | 恻隐之心 → 共情 → 亲社会行为 |
| 相关理论 | 哪些理论在解释同一现象？ | 共情-利他假说 vs 负面状态缓解模型 |
| 经典研究/案例 | 有没有著名实验、历史事件？ | 阿克塞尔罗德重复囚徒困境锦标赛 |
| 反例与争议 | 什么时候不成立？谁反对？ | 康德动机论对后果论的批评 |
- 可加一项跨学科对照（经济学、生物学、中国思想的不同说法）。
- 延展 ≤ 主体；争议并列呈现，不替主人下结论；与主人立场不同的放「相关视角」，语气中性。

## 5. 质量标准
- 能用一句大白话复述（费曼测试）；每个学术断言可追到出处；至少关联 1 篇库内旧笔记（没有就注明新领域）；素材错误在「来源与核对说明」纠正。

## 6. 常见陷阱
- 流行词与学术原义混用（如「内卷」原义见格尔茨 Agricultural Involution, 1963；用前核实）。
- 相关当因果；单个研究当定论（注意心理学可重复性危机，查是否被重复）。
- 名人背书的伪引言 → 转 `quotes-and-allusions`。
