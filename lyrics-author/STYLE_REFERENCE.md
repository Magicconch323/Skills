# 作者语料风格摘要（从 `e:/coding/知识库/歌词` 提炼）

本文件随语料更新而更新。与主 `SKILL.md` 中的「模板原则」冲突时，以**作者既有作品习惯**为准，并在对话中说明取舍。

## 「味道」在这里指什么（重点）

核心是**语音 + 句法**的联合习惯，尤其是每句话内部及相邻句之间的**声母、韵母、声调**组织规律：

- **声母连接**：某些声母类型反复出现，形成口风质感（硬、软、倔、黏）。
- **韵母黏性**：韵腹/韵尾的复现让句群自然连在一起，不只依赖行尾押韵。
- **声调波形**：上扬、下坠、平稳的组合会改变追问感、落锤感、留白感。
- **句法与语音耦合**：问句、叠句、断行不仅有语义功能，也在听感上塑形。

**不是**「这首歌情绪有多满」；情绪偏淡、留白多的作品，同样能提供稳定的语音与句法证据。

## 小样本推断纪律

- **高频**：在≥2 首中出现，或同一首里同一套路反复出现，可写进下文「用词与句法雷达」并标为稳定习惯。
- **单次 / 待验证**：仅见一次但很鲜明，可记入雷达或「语言技法」并**标明待验证**，不改成 SKILL 里的硬规则。
- **证据**：每条概括尽量带**原文中的极短引证**（几个词、半句即可），方便日后对照；避免用空泛形容词代替作者自己的说法。
- **不代客升格**：语料整体偏克制时，蒸馏文件与新词仍尊重该尺度，除非用户明确要求更外放的情绪。

## 声音与主题

- **视角**：第一人称内省为主；可对「你」倾诉，也可用第三人称叙事铺垫（如《燃烧的篝火》前传）。
- **母题**：自我与他人叙事（「你只是听说」）、命运与选择（因果/是否还是我）、出走与旅程（「去吧」「陌生人的故乡」）、用具体物象做**提问对象**（篝火、星星、旋律）。
- **气质**：叛逆与温柔并存；可带黑色幽默；**不强行治愈**，允许无力与未解之问收尾。

## 结构习惯（来自成品与草稿）

- **副歌驱动**：重复钩子句 + 排比推进（如「燃烧的篝火请你告诉我」多段堆叠）；或同一诗节首句反复（「你只是听说」）。
- **列表/并置**：情绪或人群标签并排（「恨我的 羡慕的 嫉妒的 讨厌我的」），增强节奏与画面密度。
- **括号**：舞台提示或旁白（「此刻只谈理想」）、口语补刀。
- **祈祷/宣告链**：《我对我自己说》用「我祈祷 ×N」短句咒语式堆叠，再转入「你是晴空的闪电 惊醒乌云的寂寞 / 你是燃烧的篝火 燃尽世间的罪恶」式**「你是 + 物象 + 动宾」宣告句**收束；这是作者写「硬/燃」段落的既有路径，适合战歌、宣言类副歌复用。（2 首可见：篝火、对自己说；稳定。）
- **记忆递进**：新样本《绽放》强化「我记得 / 如果我忘了 / 请你告诉我」式链条，先用短句堆起具体时刻，再把记忆交给对方确认。
- **前传/长叙事**：偶尔用一段小说式开篇再进入歌词（篝火篇）；**默认不写**，除非用户要「故事感+歌词」。
- **草稿标记**：作者文件里常见 `xxxx`、✅ 占位；代写时**不输出**占位符，除非用户要求保留草稿形态。

## 用词与句法雷达（随语料扩充；与「语言技法」互为补充）

维护方式：语料每增删改，扫一遍全文，把**可计数、可复述**的习惯填进下列子弹；尚无把握就写「待下一批语料」。

- **问句与呼告**：副歌或高潮向物象/命运发问；物象可被「你」化。（证据：语料中问句行、呼告行。）
- **叠句与首句反复**：同一句或同头在段内多次出现，形成记忆钩。（证据：待标具体篇目与句头。）
- **列表并置**：标签、人群或情绪并排，增强节奏。（证据：语料中排比行。）
- **口语嫁接非人主语**：日常动词/评价用在物象上。（例型见下节「口语嫁接物象」。）
- **虚词与语尾**：常用「吧」「啊」「呢」「而已」做轻落点；口语问句后常不急着给答案。（证据：「去吧」「那又怎样呢」「不在而已」。）
- **行幅**：偏短句为主，副歌句眼常 6-10 字；叙事铺垫处偶见长句换气。（证据：「全部告诉我」「去所有的地方」。）

## 语音味道雷达（重点追踪）

维护方式：每次新增语料时，至少抽取 8-16 行代表句，观察并记录下面条目；一次证据不足就标「待验证」。

- **声母簇**：副歌句眼偏爱爆破音/舌尖音开头形成落点，如「告诉我」「都」「听」；柔性段落用鼻音、零声母缓冲，如「我记得」「云朵」。（待更多样本验证。）
- **韵母簇**：`uo/o/e` 类开口韵常连成钩子（「告诉我」「关于我」「记得」），适合口语化反复；`ang/ao` 在出走、远方类句子里拉开空间感（「海洋」「阻挡」「地方」）。
- **声调分布**：呼告/祈愿句多用平稳开头后落到去声或上声，形成“问出去但不收死”的感觉；副歌末句可用低落口语留白。
- **拗口风险**：避免连续抽象名词和硬押韵；若一行出现多组齿音/翘舌音，优先拆短句。
- **对照短证据**：「请你告诉我」「你只是听说」「全部告诉我」「那又怎样呢」。

## 语言技法（作者高频）

- **口语嫁接物象**：把日常对话用在非人对象上（「他不会抬杠，也不会泼冷水」→ 篝火）。
- **问句副歌**：向物象提问，追问命运与自我认同；答句可保留悖论（飞蛾 / 星河）。
- **具体承载抽象**：用「空凤梨罐头」「黑色幽默」「枷锁」等具体词承载情绪，避免空喊。
- **小物件见关系**：新增样本继续把季节、云朵、影子、罐头等物件当作情绪容器；写食物题材时应让味道牵出关系，而不是只报菜名。
- **古典/地名意象**：个别作品（如《听》）会出现较强文学化堆叠（广陵、敦煌等）。**默认**仍以口语化为主；若用户指定「像《听》那种」再拉高文学密度，并避免生僻字堆砌。

## 应避免（与作者自述一致）

- 把用户素材名词直接钉进词里（素材→情绪与关系→再落笔）。
- 陈词滥调与两行以上纯写景。
- 为押韵牺牲语义（作者仍重语感与节奏，韵脚自然即可）。

## 示例钩子（仅供音色对齐，勿照抄）

- 提问式：「……请你告诉我」「是否……」
- 叠句：「你只是听说 / 从他们嘴里听说」
- 出走：「去吧 / 去所有的地方 / 去看那片海洋」
