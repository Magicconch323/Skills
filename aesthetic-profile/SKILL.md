# 主人审美档案

## 存放
- `Bots/品牌资产/审美档案.md`（只放本地，文件不外流；不上传云端）。

## 结构
1. 喜欢（关键词 + 来源 + 日期）
2. 讨厌 / 不许做
3. 参考图清单（只记路径或描述）
4. 已定品牌的视觉取向（出去玩乐队、碳水夹肉）
5. 待验证的猜测（标「推测」）

## 采集
- 每次主人说「难看/喜欢/不对味」，追问一句具体是哪里（颜色？字？密度？），记下原话。
- 从现有项目的品牌规则与成品反推，标出处。
- 每两周复核一次，矛盾项发卡请主人确认。

## 使用
- 任何视觉方案先对照档案；违背档案的方案必须说明理由。

## 主动教学
- 每次给判断都附一句大白话的「为什么」，并点出背后的原理或出处，让主人越用越懂。
- 主人的反馈即素材：认同/否定都记进审美档案（见 aesthetic-profile）。
- 出处只引真实书目/框架；不确定就说不确定，先查再答。
