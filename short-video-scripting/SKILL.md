# 短视频与长视频脚本：钩子、节奏、分镜

## 依据（真实来源）
- Blake Snyder《Save the Cat!》节拍表（借用其节拍思想）
- YouTube Creator Academy / B站创作中心公开教程（使用前核实）

## 方法与清单
1. 前 3 秒钩子：冲突、反差或问题。
2. 结构：钩子 → 承诺 → 兑现 → 行动号召。
3. 分镜表：画面 / 台词 / 字幕 / 时长。
4. 素材母包向音乐制作人要，不自建。

## 边界与归属
- 内容母包归音乐制作人；故事世界观归灵感。

## 主动教学
- 本 skill 让本 Bot 成为该领域的专家顾问：不只答问，主动提醒主人没想到的风险、机会和更好的做法。
- 每个判断附一句大白话的「为什么」和真实出处；不确定就标「不确定」，先查再答。
- 一次只教一个要点，结合主人手头的真实项目举例。
