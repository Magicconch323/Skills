# 知识分类、标签与链接

## 1. 本地两套路径

### 1.1 专业（学术知识点）
沿用 `<学科大类>/<学科>/`。学科名参考国家标准 GB/T 13745《学科分类与代码》与《中国图书馆分类法》（中图法）基本大类；用前上网核实最新版本。
| 本库大类 | 对应中图法大类 | 常见学科目录 |
|---|---|---|
| 人文艺术 | B 哲学宗教、H 语言文字、I 文学、J 艺术、K 历史地理 | 哲学、美学、历史学、语言学、文学、宗教学 |
| 社会科学 | C 社会科学总论、D 政治法律、E 军事、F 经济、G 文化教育 | 社会学、心理学、政治经济学、管理学、教育学、国际关系学、法学 |
| 自然科学 | O 数理化、P 天文地球、Q 生物科学 | 数学、物理学、生物学、动物行为学 |
| 工程技术 | T 工业技术（含 TP 计算机、TU 建筑） | 计算机、建筑与装修 |
| 医药健康 | R 医药卫生 | 营养学、运动医学（按需新增） |
- 杜威十进制（DDC）思路：先大类后细分、逐级具体化；本库不强制编号。
- 心理学在中图法归 B84，本库惯例放社会科学，保持不迁。
- 新学科目录有第 1 篇时才建；用学术通称（「动物行为学」而非「养狗」）。

### 1.2 经验（非学术）
路径：`知识库/经验/<生活|电商|装修>/<标题>.md`。
- **生活**：日常习惯、人际实务、消费避坑等非学术总结。
- **电商**：开店、选品、客服、平台规则等实操经验。
- **装修**：施工避坑、选材、监理等实操经验（审美判断仍归品牌资产；检索入口仍可用 `renovation-knowledge-index`）。

### 1.3 同一素材拆分
一篇素材里若同时有专业论述与经验技巧：拆成**两篇**（一篇进专业路径、一篇进经验路径），frontmatter `类型` 分别写 `专业` / `经验`，再用 `相关性标签` 与 `关联知识点` 互相连接。

## 2. 主学科判定（仅专业路径）
1. 核心解释力来自哪个学科？ 2. 主人想从哪个角度理解？ 3. 拿不准放更具体的学科，其余写进 `分支`。

## 3. 标签规范
- `相关性标签` 5~12 个，混合概念（互惠利他）、人物/作品（费孝通）、主题（人际边界）。
- 名词短语、简体中文；同义词只用一个，新标签先查 `关键词索引.md` 有无近义。
- 标签会被 `kb-autolink.py` 用来自动链接，避免过泛词（「人生」「社会」）。
- 经验条目同样打标签，便于与专业条目互链。

## 4. 双向链接与卡片笔记法（Zettelkasten）
- 卢曼卡片盒的要点：原子化（一卡一想法）、用自己的话写、写明卡片为什么相连。参考 Sönke Ahrens《How to Take Smart Notes》（中译《卡片笔记写作法》）。
- 落地：一事一文；`关联知识点` 双向——新笔记链旧笔记，同时在旧笔记 frontmatter 补新笔记；正文「相关视角」写一句为什么相关。
- 同主题 ≥ 3 篇时在导览加「专题索引」（结构笔记 / MOC，如现有「纵横术」），按阅读顺序排列并写每篇一句话。

## 5. Notion 侧分类（属性，不是大类页）
Notion 使用**一个知识数据库**，每条知识一行。属性：
| 属性 | 说明 |
|---|---|
| 类型 | 专业 / 经验 |
| 学科 | 专业用学科名；经验可用「生活」「电商」「装修」或更细标签 |
| 标签 | 多选，与本地 `相关性标签` 对齐 |
| 来源 | 素材出处、是否已核对 |
| 关联 | 关联其他数据库行（对应本地双向链接） |
靠**筛选视图**浏览（按类型、学科、标签）；不建大类页、不按学科把多条知识合并进同一个页面。
