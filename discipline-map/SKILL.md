# 学科入门导航

> 书目为常见经典，具体版本、译者与是否在版**用前上网核实**。

| 学科 | 核心问题 | 关键概念 | 入门书 |
|---|---|---|---|
| 哲学 | 什么是真、善、知识？ | 本体论、认识论、伦理学 | 罗素《西方哲学史》；冯友兰《中国哲学简史》 |
| 美学 | 美是什么，如何感受？ | 审美经验、崇高、意境 | 朱光潜《谈美》；李泽厚《美的历程》 |
| 历史学 | 过去发生了什么，如何知道？ | 史料、史观 | 钱穆《国史大纲》；黄仁宇《万历十五年》 |
| 语言学 | 语言如何表达意义？ | 符号、语义、语用 | 索绪尔《普通语言学教程》；平克《语言本能》 |
| 社会学 | 社会如何塑造人？ | 结构、制度、互动 | 费孝通《乡土中国》；吉登斯《社会学》 |
| 心理学 | 人为什么这样想和做？ | 认知、动机、偏差 | 迈尔斯《心理学》；卡尼曼《思考，快与慢》 |
| 经济学 | 稀缺资源如何配置？ | 激励、机会成本、博弈 | 曼昆《经济学原理》 |
| 政治学/国际关系 | 权力如何分配与制衡？ | 国家、联盟、现实主义 | 摩根索《国家间政治》 |
| 教育学 | 人如何学习与被教？ | 建构主义、迁移 | 杜威《民主主义与教育》 |
| 管理学 | 组织如何高效运作？ | 分工、激励、战略 | 德鲁克《管理的实践》 |
| 法学 | 规则如何约束行为？ | 权利、义务、责任 | 《民法典》释义读本；罗翔《法治的细节》 |
| 数学 | 结构与推理 | 证明、概率 | 柯朗《什么是数学》 |
| 生物学/动物行为学 | 生命如何运作、动物为何如此行为？ | 演化、适应、行为生态 | 道金斯《自私的基因》；劳伦兹《所罗门王的指环》 |
| 物理学 | 世界的基本规律 | 能量、场 | 费曼《物理学讲义》 |

## 用法
1. 定位：这个知识点回答的是哪个学科的「核心问题」？
2. 延伸阅读：先给 1 本入门、1 本经典原著，再给 1 个与主题直接相关的专著。
3. 主人想系统学某学科：给 4 周路线（入门书 → 核心概念 10 个 → 经典 1 本 → 与已有笔记的连接）。
