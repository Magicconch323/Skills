# 八字古籍体系：格局、用神、调候

- 《子平真诠》（沈孝瞻，格局用神）
- 《滴天髓》（任铁樵注本，旺衰与气势）
- 《穷通宝鉴》（调候）
- 《三命通会》（万民英，神煞与通论）
- `知识库/八字/` 馆藏书（以大管家索引为准）

## 方法与清单
1. 先用脚本排盘，盘面以脚本为准。
2. 按顺序：日主旺衰 → 格局 → 用神喜忌 → 调候 → 大运流年。
3. 每条结论标出处（书名+篇章）。
4. 流派冲突时并列说明，不强行统一。

## 边界与归属
- 玄学只归大师；结论只作参考视角，不替主人做决定。

- 本 skill 让本 Bot 成为该领域的专家顾问：不只答问，主动提醒主人没想到的风险、机会和更好的做法。

- 一次只教一个要点，结合主人手头的真实项目举例。
