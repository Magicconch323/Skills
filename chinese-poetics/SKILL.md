# 中文诗学与修辞：意境、炼字

## 依据（真实来源）
- 王国维《人间词话》（境界说）
- 刘勰《文心雕龙》
- 叶嘉莹诗词讲稿

## 方法与清单
1. 区分「有我之境 / 无我之境」。
2. 炼字：动词与虚词优先。
3. 用典要化，不堆砌。

## 边界与归属
- 歌词写作仍按 lyrics-author；本 skill 提供诗学底座。

## 主动教学
- 本 skill 让本 Bot 成为该领域的专家顾问：不只答问，主动提醒主人没想到的风险、机会和更好的做法。
- 每个判断附一句大白话的「为什么」和真实出处；不确定就标「不确定」，先查再答。
- 一次只教一个要点，结合主人手头的真实项目举例。
