# 知识笔记格式与排版

## 1. 文件
- UTF-8（无 BOM）；扩展名 `.md`；文件名 = 知识点标题，去掉 `/ \ : * ? " < > |` 和引号，不加日期（日期写 frontmatter）。
- 路径 `知识库/<学科大类>/<学科>/<标题>.md`，一事一文。

## 2. frontmatter（YAML，放文件第一行）
```yaml
---
类型: 知识点
学科: 社会学
分支: [伦理学, 心理学]
相关性标签: [善良, 互惠利他]
关联知识点: [社会科学/社会学/人情世故的异化与说不的主体性.md]
收录日期: 2026-10-16
来源说明: 素材来源；整理者；引语核对情况
---
```
- 新笔记列表用 `[a, b]` 行内写法；关联路径写相对知识库根的路径。
- 值里含冒号或 `#` 时加引号。

## 3. 标题层级
- 全文只有一个 H1：`# 知识点：<标题>`。
- 节用 H2（`## 1. 核心观点`），小节 H3（`### 2.1 …`）；不跳级。Notion 只有 H1–H3，H4 会变成普通段落，所以止于 H3。

## 4. 中文排版（参考 sparanoid《中文文案排版指北》、W3C《中文排版需求》clreq；用前上网核对最新版）
- 中文与英文、数字之间加半角空格：`在 Notion 里`、`共 21 个`；`5 MB`、`20%`、`3 天`。
- 中文语境用全角标点：，。？！：；「」『』（）——……；全角标点前后不加空格。
- 本库统一用直角引号「」，内层用『』；书名《》，篇名《书名·篇名》。
- 不连用感叹号；省略号「……」；破折号「——」。
- 专有名词大小写正确：GitHub、iPhone、Notion。

## 5. Notion 兼容写法
| 效果 | 本地 Markdown | Notion 中 |
|---|---|---|
| 提示框 callout | `> 💡 **一句话说清**：…`（emoji 开头的引用块） | 同步时转 callout |
| 折叠 toggle | `<details><summary>标题</summary>内容</details>` | 转 toggle |
| 引用 / 书摘 | `> 「原文」` 换行 `> ——作者《书名》` | quote 块 |
| 表格 | 标准管道表格，首行表头 | simple table；单元格内不换行、不嵌列表 |
| 代码 | 三反引号加语言 | code 块 |
| 内链 | 相对路径 `[标题](../社会学/x.md)` | 同步时转 page mention |
- 不用 HTML 样式、颜色、脚注 `[^1]`（Notion 导入不支持）；出处写行内「——出处」或文末「来源」节。
- 图片放同目录 `assets/`，同步时上传。

## 6. 长文可读性
- 开头放「一句话说清」callout。
- 段落 ≤ 5 行，一段一个意思；列表项 ≤ 2 行。
- 每 300~500 字出现小标题、表格、引用或例子，避免文字墙。
- 粗体只标关键词，一段最多 1~2 处。
- 术语首次出现：`互惠利他（reciprocal altruism）：……` 中英对照 + 一句解释。
- 链接写 `[名称](URL)`，不贴裸链。

## 7. 交付前自查
- [ ] frontmatter 可解析 · [ ] 只有一个 H1 · [ ] 中英文空格、全角标点 · [ ] 表格无单元格换行 · [ ] 引文有出处 · [ ] 内链路径存在
