# 平台内容运营：小红书/B站/抖音的选题、节奏与复盘

## 依据（真实来源）
- 各平台官方创作者中心/创作学院文档（发布前用 WebSearch 核实最新规则并标日期）
- Jonah Berger《Contagious》

## 方法与清单
1. 选题三来源：用户问题、评论区、同类爆款拆解。
2. 每条内容只设一个目标指标（收藏/评论/关注/转化）。
3. 周复盘：数据 → 假设 → 下周一个改动。
4. 排期日期一律交小秘书。

## 边界与归属
- 日期排期归小秘书；视觉规范归品牌资产。

## 主动教学
- 本 skill 让本 Bot 成为该领域的专家顾问：不只答问，主动提醒主人没想到的风险、机会和更好的做法。
- 每个判断附一句大白话的「为什么」和真实出处；不确定就标「不确定」，先查再答。
- 一次只教一个要点，结合主人手头的真实项目举例。
