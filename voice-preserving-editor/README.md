# Voice Preserving Editor：中文去 AI 腔与个人写作风格润色 Skill

很多“去 AI 味”工具只是把一批词换成另一批词，最后文章更口语，却不像原作者。真正的编辑应该保留事实、立场和节奏，只处理模板感、空话和不自然的组织方式。

`voice-preserving-editor` 是一个面向中文和英文写作的开源去 AI 腔与个人风格润色 Agent Skill。它先锁定事实、立场和作者声音，再处理模板化句式、空话、宣传腔、重复结构和不自然过渡。兼容 Codex、Claude Code、Cursor 和 OpenCode 等支持 `SKILL.md` 的工具。

## 使用示例

```text
用 $voice-preserving-editor 编辑这篇文章。
这是我以前写的一段文字，请保持我的句子节奏和直接程度。
不要增加新观点，也不要为了口语化删掉事实。
```

## 它不会做什么

- 不承诺绕过 AI 检测器
- 不伪装作者身份或写作过程
- 不自动增加个人经历、情绪和观点
- 不为了“更像人”故意加入错误

## 安装

```bash
cp -R skills/voice-preserving-editor ~/.codex/skills/
```

## 适用场景

- 中文文章去 AI 腔、博客润色和公众号改稿
- 根据历史样本匹配个人写作风格
- 保留原意、事实和立场的文章改写
- 减少空泛总结、宣传腔、机械连接词和模板句式
- 技术文章、研究内容和品牌文案的语气校准

## 常见问题

### 它能绕过 AI 检测器吗？

不承诺，也不以绕过检测为目标。它解决的是文本质量和作者声音问题，不帮助规避学术诚信或平台审核。

### 没有个人写作样本怎么办？

会采用中性、克制的编辑方式，只减少明显模板感，不擅自增加个人经历、观点或情绪。

### 会不会删掉原文的重要信息？

编辑前会锁定数字、日期、名称、条件和立场，修改后再检查信息是否丢失或新增。
