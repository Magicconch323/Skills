## 一、装修流程总览

**完整装修步骤（12步）：**
收房验房 → 拆除 → 门窗测量 → 中央空调/新风 → 水电改造 → 防水 → 瓦工（贴砖） → 美缝 → 木工（吊顶） → 油工（涂料） → 主材安装 → 软装入场

**核心原则：** 半包方式性价比最高；付款方式建议3-3-3-1（开工30%、瓦工完30%、油工完30%、完工10%）
