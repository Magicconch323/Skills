# 交通事故处理（《道路交通安全法》及实施条例、相关司法解释；用前核对）

## 现场
1. 开危险报警灯、放警告标志（高速 150 米外），人员撤到安全处；有人受伤先打 120、110/122。
2. 拍照：全景、碰撞部位、车牌、路面痕迹、对方驾驶证行驶证和保险单。
3. 无人伤亡、车能动、事实清楚：可撤离现场自行协商或用「交管 12123」快处快赔。
4. 有人伤亡或对方酒驾、无证、逃逸：保护现场、报警，不私了。

## 责任与理赔
- 交警出具事故认定书；对认定不服可在收到后 3 日内申请复核（核实）。
- 先由交强险在限额内赔付（含无责限额），不足部分按责任比例由商业三者险赔，再不足由责任人承担。
- 赔偿项目：医疗费、误工费、护理费、交通费、营养费、残疾赔偿金、精神损害抚慰金、财产损失等。
- 机动车与非机动车、行人间：机动车一方即使无过错也承担不超过 10% 的赔偿责任。

## 后续
- 保存病历、发票、误工证明；伤残需鉴定；协商不成可申请交警调解或起诉（时效 3 年，见 legal-procedure-evidence）。
